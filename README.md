# Web Traffic Analytics

## Project Overview
This project analyzes website traffic data to understand visitor behavior, engagement, traffic sources, and registration conversion performance.

Completed as part of the **Workora Data Analytics Virtual Internship**.

## Objectives
- Analyze website traffic sources.
- Calculate bounce rate and average session duration.
- Evaluate pageviews and landing-page performance.
- Compare registration conversions across traffic sources.
- Analyze user behavior by device category.
- Identify registration funnel drop-offs.
- Present insights through visualizations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- `web_traffic_analysis.ipynb` – Data analysis notebook
- `web_traffic_analytics_v2.csv` – Original dataset
- `output/` – Analysis tables and dashboard report
- `output/charts/` – Data visualization charts

## Key Results
- Total Sessions: 900
- Registration Starts: 277
- Completed Registrations: 166
- Overall Conversion Rate: 18.44%
- Bounce Rate: 4.89%
- Average Session Duration: 243.49 seconds
- Average Pageviews: 3.45

## Key Insights
- Instagram achieved the highest conversion rate at 23.66%.
- Google Organic generated the highest traffic volume.
- Desktop users had the highest conversion rate.
- Mobile devices generated the largest share of sessions.
- The homepage recorded the highest registration drop-off count.
